# Installation guide

## Requirements

- WordPress 6.0+
- PHP 7.4+
- HTTPS recommended

## Steps

1. Upload **termimal-theme.zip** via Appearance → Themes → Add New → Upload
2. Upload **termimal-core-plugin.zip** via Plugins → Add New → Upload
3. Activate the **TERMIMAL** theme
4. Activate **TERMIMAL Core** plugin
5. Settings → Permanent Links → Save (flush rewrite rules)
6. Optional: Settings → General → Anyone can register
7. Settings → TERMIMAL → particles, GA4, webhooks

## First product

1. Products → Add New
2. Set title + excerpt
3. Sidebar: **TERMIMAL Cover** → select image
4. **TERMIMAL Details** → status, links, tech
5. Assign category
6. Publish

## Account pages

Plugin auto-creates `/login/`, `/register/`, `/profile/` if missing.
